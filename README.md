
🍽️ Recipe Finder App

A simple and interactive Recipe Finder App built using HTML, CSS, and JavaScript.
Users can type any ingredient (e.g., “chicken”, “egg”, “rice”) and the app instantly shows delicious recipes fetched from TheMealDB API.

✨ Features

🔍 Search by Ingredient
Type any food ingredient and get recipes instantly.

🖼️ Recipe Cards with Images
Every recipe shows an image, title, and category.

📖 View Full Recipe Instructions
A button that opens detailed cooking steps & video link.

⚡ Fast & Lightweight
No frameworks — pure HTML, CSS, and JavaScript.

🌐 Live API Data
Uses TheMealDB to fetch fresh and real recipes.

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

API: TheMealDB (https://themealdb.com/api.php
)

No backend required — everything runs in browser

▶️ How to Run

Simply open the recipefinder.html file in any browser.

No installation required.

# Just double-click
recipefinder.html

📁 Project Structure
Recipe-Finder/

   ├── (optional assets)   # images, icons if added

💡 Motivation

Finding recipes quickly should be easy.
This project helps users discover recipes based on simple household ingredients
— perfect for students, beginners, or anyone needing cooking ideas.
